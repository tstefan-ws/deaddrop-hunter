# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. By participating (issues, pull requests, discussions, reviews)
you agree to abide by its terms.

In addition, because this is a threat-intelligence project:

- Do not post live malware, credentials, private keys, or personal data of victims.
- Do not dox or harass people, including suspected operators. Report on-chain artifacts
  and infrastructure, not individuals.
- Keep shared material TLP:CLEAR and defang indicators in prose.

## Reporting

Report unacceptable behavior privately to the maintainers via
[GitHub private vulnerability reporting / security advisories](../../security/advisories/new)
or by contacting a maintainer listed in the repository. All reports are reviewed
and handled confidentially. Enforcement follows the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
